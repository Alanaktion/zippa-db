### Core UI Theme Variables

| UI Token | Dark Mode (Default) | Light Mode | Application & Usage |
| --- | --- | --- | --- |
| **Base Surface** | `#16171D` | `#F4F5F8` | Main canvas, query editor background, app frame |
| **Panel Surface** | `#1C1E26` | `#FFFFFF` | Sidebars, tab bars, table header containers |
| **Subtle Surface** | `#242734` | `#EAECEF` | Hover states, zebra striping on data tables |
| **Border / Divider** | `#2E3244` | `#D5D8E1` | Panel splits, gridlines, input boundaries |
| **Text Primary** | `#C0CAF5` | `#1E202B` | Main content, column headers, cell values |
| **Text Muted** | `#565F89` | `#6C7393` | Secondary text, row counts, disabled states |
| **Primary Accent** | `#37505C` | `#4C6E7E` | Active selection, focused table cell borders |
| **Secondary Accent** | `#BB9AF7` | `#7C4DFF` | Primary action buttons, active tab indicator, key bindings |
| **Selection / Highlight** | `#2A324B` | `#D9E2FF` | Text selection, multi-row table highlights |

### Database Engine Badges

Database badges use slightly deeper tints in Light Mode to preserve text contrast while maintaining visual harmony:

| Database Engine | Dark Mode Badge | Light Mode Badge | Accent Border / Text |
| --- | --- | --- | --- |
| **MySQL** | `#E0AF68` | `#D97706` | Warm Amber / Gold |
| **PostgreSQL** | `#7AA2F7` | `#2563EB` | Cobalt Slate Blue |
| **SQLite** | `#7DCFFF` | `#0284C7` | Pale Cyan / Soft Blue |

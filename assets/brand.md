# Zippa DB Brand

The aesthetic should feel razor-sharp, lightweight, and focused. Because database tools are high-density environments, subtle tone-on-tone accents paired with distinct database engine visual markers work best.

### UI Accent Palette

Instead of relying on loud primary colors, ground the UI in cool charcoal-slate neutrals paired with muted, desaturated atmospheric accents:

| Token | Hex | Usage & Context |
| --- | --- | --- |
| **Base Surface** | `#16171D` | Deep cool charcoal background for main panels and editor frames. |
| **Panel Surface** | `#1C1E26` | Slightly lighter container gray for sidebars, tabs, and table headers. |
| **Primary Accent** | `#37505C` | Muted desaturated slate-teal for active selection states, focused borders, and tab highlights. |
| **Secondary Accent** | `#BB9AF7` | Soft lavender for syntax highlighting keywords, primary CTA buttons, and active cursor focus. |
| **Muted Accent** | `#565F89` | Cool grey-blue for secondary text, dim borders, and scrollbars. |

#### Database Engine Indicators

Use distinct color-coded badges for database engines:

* **MySQL:** Soft Amber/Warm Coral (`#E0AF68` / `#F7768E`)
* **Postgres:** Slate Blue (`#7AA2F7`)
* **SQLite:** Pale Mint / Cyan (`#7DCFFF`)

### App Icon Concept

A database GUI needs an icon that translates cleanly down to small dock dimensions while conveying speed and structured data.

* **Shape & Geometry:** A rounded squircle frame (matching modern macOS / desktop guidelines) housing a stylized, high-speed database stack.
* **Core Motif ("Zippa"):**
* Three horizontal stacked database discs floating vertically.
* A sharp, minimal lightning bolt or "Z" cut intersecting diagonally through the right edge of the stacked cylinders, representing instantaneous query execution and the lightweight Rust core.

* **Color Direction:** A smooth gradient backdrop transitioning from deep nocturnal slate (`#13141C`) to muted indigo blue (`#1F2335`), with the stacked database cylinders rendered in silver-white metallic stroke lineart and highlighted by a soft violet/lavender stroke along the diagonal cut.

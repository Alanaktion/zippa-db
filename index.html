Engineered for Your Core Stack

Native drivers with zero wrapper overhead. Connect directly to local or cloud-hosted instances.

PostgreSQL

PG v10+

Full support for JSONB value rendering, an EXPLAIN ANALYZE visualizer, and rich display for Postgres types.

  • Process list with KILL
  • Server variables & query digest
  • SSH tunneling (coming soon)

MySQL / MariaDB

MySQL 8.0+

Visual schema editor that generates ALTER statements, with stored routines browsable right in the schema tree.

  • Process list with KILL
  • Server variables & query digest
  • SSH tunneling (coming soon)

SQLite

Embedded

Zero-config file opening, plus a maintenance panel for the chores SQLite files need over time.

  • VACUUM & integrity checks
  • WAL checkpoint

Designed for Speed & Focus

Everything you need in a modern database tool, stripped of bloated legacy web views.

GPU-Accelerated Rendering

GPUI draws the interface on the graphics processor, so scrolling grids and resizing panes stays smooth.

Quick Switcher

Fuzzy-find tables, commands, and databases from a single keyboard-driven palette.

Native Enclave Vault

Credentials and SSH keys are stored in system Keychain / SecretService with zero third-party telemetry.

Query Console

Every statement you run is logged to a per-session console, so previous queries are always a scroll away.

Data Export

Dump result sets or whole tables to CSV, JSON, or SQL with a couple of clicks.

Light & Dark Themes

Polished themes for both modes out of the box, with custom theme files if you want your own palette.

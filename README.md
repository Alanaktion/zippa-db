# ZippaDB

A clean, simple database client for Linux, written in Go.

## Building

Requires Go 1.8+ (1.12+ recommended), and GTK3+ development libraries.

We have a build script that builds the package in `./src`:

```bash
./build.sh
```

This will leave a `zippa-db` binary in the current directory.

## Development

### Go source

You'll need a recent (1.8+ *at least*) Go environment, and ideally VS Code installed with the official Go extension. The main app source code is in `src/`, and relies on a few third-party packages for GTK and MySQL functionality.

### .ui files

The `src/ui/*.ui` XML files are used to generate the various windows in the application, and are generated by [Glade](https://glade.gnome.org/) on Linux, but can be manually edited as text if desired. Editing with Glade makes visualizing interface changes much easier, but can be unnecessary for small edits, and limiting for large replacements.

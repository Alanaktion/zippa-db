# ZippaDB

[![Build](https://github.com/Alanaktion/zippa-db/actions/workflows/build.yml/badge.svg)](https://github.com/Alanaktion/zippa-db/actions/workflows/build.yml)

A clean, simple database client for Linux, written in Go.

## Building

Requires Go 1.16+ (for embed support) and GTK3+ development libraries. This project is tested with the latest Go version.

### Install Dependencies

On Ubuntu/Debian:
```bash
sudo apt-get install libgtk-3-dev
```

On Arch Linux:
```bash
sudo pacman -S gtk3
```

On Fedora/RHEL:
```bash
sudo dnf install gtk3-devel
```

### Build the Application

The project uses Go modules for dependency management. Simply run:

```bash
./build.sh
```

This will:
1. Download and cache all Go dependencies
2. Build the application binary in the `build/` directory

You can also build manually with:
```bash
go build -o ./build/zippa-db ./src
```

All dependencies are managed through `go.mod` and will be automatically downloaded on first build.

### Cross-compiling for Windows

We'll follow [gotk3's Cross Compiling wiki](https://github.com/gotk3/gotk3/wiki/Cross-Compiling). A Dockerfile is provided in `build/windows/` that *should* create an environment with all the build tools necessary.

Note that on Arch Linux, the mingw packages can be installed pre-compiled from [ownstuff's user repository](https://wiki.archlinux.org/index.php/unofficial_user_repositories#ownstuff).

## Development

### Go source

You'll need Go 1.16+ (for embed support) with Go modules enabled. The main app source code is in `src/`, and uses the following dependencies:
- [gotk3/gotk3](https://github.com/gotk3/gotk3) - Go bindings for GTK3
- [go-sql-driver/mysql](https://github.com/go-sql-driver/mysql) - MySQL driver
- [spf13/viper](https://github.com/spf13/viper) - Configuration management

All dependencies are managed through `go.mod` and will be automatically fetched when building.

### .ui files

The `src/ui/*.ui` XML files are used to generate the various windows in the application, and are generated by [Glade](https://glade.gnome.org/) on Linux, but can be manually edited as text if desired. Editing with Glade makes visualizing interface changes much easier, but can be unnecessary for small edits, and limiting for large replacements.

The .ui files are embedded directly into the application binary using Go's native `embed` package (available since Go 1.16). This allows us to work off of local files during development, but build the app as a single file for distribution.
